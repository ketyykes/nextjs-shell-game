使用方式

每台終端機列出的是 src/game/chapters/solutions.ts 裡經單元測試（solutions.test.ts）用真 Shell 驗過的正解序列，照順序一行一行打，最後一行打完就過關。前面幾行多半是「讀劇情」用，但有些關卡的判定要靠前面的指令改變檔案系統或環境變數（例如第三章 T4、第六章 T6），所以直接整串照抄最保險。

終端機的輸入列是單行輸入框，貼多行會被合併成一行。所以「複製全部」把整串指令用 ; 串成一行，貼上按一次 Enter 就全部執行，shell 會逐段判定目標。想一行一行打就自己從清單抄。

第一次用「複製全部」過關時，「目標達成」下面會多一行「☆ ; 不在課表上，你自己找到的。」：這是「提前用上的認可」，整份存檔只出現一次，屬預期。

  • 操作：方向鍵或 WASD 走路，走到終端機前按 E 開啟，Esc 關閉／暫停。
  • 終端機內建幫手：hint 連打三次會給到「照抄即可過關」的第三段提示；help 列已學指令；man 指令 看說明。
  • 位置：六個甲板共用同一張平面圖，T1 到 T6 固定在下面這幾個位置。

跳章與除錯鉤子

A. 直接跳到第 N 章（寫 localStorage）

在遊戲頁（任何路徑都行）的瀏覽器 console 貼下面的程式，改 chapter，然後重新整理並進 /play。寫的是目前的存檔格式 v4；e2e 的 seedSave 刻意寫 v1，舊版號都會由 migrate.ts 自動升級，兩種都能用。

(() => {
  const chapter = 3; // 改成要跳的章節 1 到 6
  const allAbinNotes = false; // true：阿彬的八則留言全部算找到（右側面板 8/8，第六章片尾多一段）
  const solvedTerminals = [];
  const storyFlags = {};
  for (let c = 1; c < chapter; c += 1) {
    storyFlags[`ch${c}.introShown`] = true;
    storyFlags[`ch${c}.outroShown`] = true;
    for (let t = 1; t <= 6; t += 1) solvedTerminals.push(`ch${c}-t${t}`);
  }
  const save = {
    state: {
      progress: {
        chapter,
        furthestChapter: chapter,
        position: null,
        character: "a",
        solvedTerminals,
        learnedCommands: [],
        oxygen: 100,
        savedAt: new Date().toISOString(),
        clearedAt: null,
      },
      settings: { textSpeed: "instant", flickerEnabled: true, flickerPromptSeen: true, scanlinesEnabled: true, vignetteEnabled: true, volume: 0.8, muted: true },
      terminals: {},
      storyFlags,
      stats: {},
      abinNotes: {
        found: allAbinNotes
          ? ["ch1-jokes", "ch2-backup", "ch2-vault", "ch3-hold", "ch4-relay", "ch4-reply", "ch5-rations", "ch6-shift"]
          : [],
        reply: null, // 想看第五、六章的回信證據，改成一句話字串，例如 "我醒了"
      },
    },
    version: 4,
  };
  localStorage.setItem("kepler9-save", JSON.stringify(save));
  location.href = "/play";
})();

想從標題畫面正規地選章：只要 furthestChapter 夠大，標題的「選章」就會開放到那一章。

B. 直接播某台終端機的過關演出（開發模式除錯鉤子）

/play 在開發模式會掛 window.__kepler9.emit，可以不打指令直接播該終端機宣告的地圖演出，例如 ch1-t4 亮燈、各章 t6 開門（正式 build 沒有）：

這個鉤子只播演出，不寫存檔：終端機不會標成過關、HUD 進度不加、章節結束不會出現，重新整理後演出也消失。要真的標成過關，用 A 段的程式把該終端機 id 加進 solvedTerminals 後重新整理。
window.__kepler9.emit("puzzle:solved", { terminalId: "ch1-t4" });

另一個鉤子 window.__kepler9Player 是角色座標探針，e2e 走路用，唯讀。

C. 清除存檔

localStorage.removeItem("kepler9-save");

阿彬的隱藏留言 選讀，不影響過關 · 集滿八則第六章片尾多一段

每則留言只放在一台終端機，在那一台的輸出裡看到留言的那一句（cat、less、grep 撈到簽名那行都算）才算找到；只列出檔名的 ls、find 不算。找到時終端機插一行「已收進「阿彬的留言」n/8」，右側面板 Alt+A（Mac ⌥A）看全文，第一章宿舍那台過關後才會出現這個標籤。

找法跟 src/game/story/abinNotes.ts 的 howToFind 一樣，有單元測試用真 Shell 跑過；相對路徑的那兩台前面多一行 cd，在別的目錄也能直接貼。只想看片尾加段：用上面跳章程式的 allAbinNotes = true 跳到第六章最省事。

重現「那三秒」 ch5-t4 安全管制台 · NOVA_DIR=/opt/nova

親手看到 unset 之後 rm 的路徑只剩根目錄

  1. echo "$NOVA_DIR/"
  2. unset NOVA_DIR
  3. echo "$NOVA_DIR/"
第一個 echo 印 /opt/nova/，unset 之後只剩 /，NOVA 會插一句並燈閃（關閉閃爍時不閃）。真的打 rm -rf "$NOVA_DIR/" 會被擋下並算一次錯誤，檔案都還在。第五章 T1 的站務變數、T5 的 POD_DIR、T6 的 AUTH_DIR 是唯讀，unset 不掉。
